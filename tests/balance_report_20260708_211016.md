## Methodology

- **Single source of truth**: unit classes + costs come from `src/unit_registry.lua`; base stats are read from live constructors. Spells are excluded (not simulated).
- **Equal budget**: both players receive the same coin budget per match.
- **Heuristic placement**: tanks → front, melee → mid, ranged + structures → back (effigy mid).
- **Unit vs unit matrix**: mono-army of each type vs every other type, averaged over budgets 12/24.
- **Draws**: stalemates (board unchanged for 10s) end early and count as half a win for each side.
- **Buy vs upgrade**: an upgrade costs the unit's base cost (same as a second copy), so 3×L1 vs 6×L0 is coin-neutral.
- **Stat search**: ±10/20% health, ±1 damage, ±0.05/0.10 attack speed vs unmodified mirror.
- **Upgrade paths**: all 1- and 2-upgrade combinations vs unupgraded same unit.
- **Balance thresholds**: >62% = overtuned, <38% = undertuned.
- **Caveat**: the sim can't value setup-phase play, spells, or clever positioning — treat results as a screen, confirm with playtests/telemetry.
